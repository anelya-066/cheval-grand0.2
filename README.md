# Cheval Grand — Фан-сайт / Портфолио

Информационный и развлекательный веб-сайт, посвященный персонажу **Cheval Grand** (Шеваль Гран) из вселенной *«Девочки-лошадки: Прекрасный дерби»* (Umamusume: Pretty Derby).

> **Note**: Сайт создан исключительно в развлекательных и образовательных целях, не является коммерческим проектом.

---

## Портфолио
Данный проект также является частью веб-портфолио и демонстрирует навыки верстки и разработки интерфейсов.

## Структура проекта
- `index.html` — главная страница
- `css/style.css` — стили и оформление
- `js/script.js` — интерактивная логика
- `images/` — графические элементы и ассеты
  
## Запуск проекта
Для локального запуска проекта достаточно открыть файл `index.html` в любом современном браузере.
